# Demo resolution notes — INC0000013 (fictional, for POC only)

**Incident:** EMAIL is slow when an attachment is involved  
**Use with:** KB Article Drafting skill

## Approved resolution steps

1. Confirm attachment size (limit: 10 MB for standard mail flow)
2. Ask user to send a plain-text email without attachment — confirm normal speed
3. If attachment-related: advise compressing file or using approved file-share link
4. Check mailbox quota and server-side limits via Email admin console
5. Confirm user can send with a small test attachment (< 1 MB)

## Escalation

Escalate to Email/Messaging team if issue persists after workaround.
